# Dillan Fernando — Frontend Developer Portfolio

A premium freelance frontend developer portfolio built with React, TypeScript, and Vite.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Customization

- **Site content**: Edit `src/data/site.ts`
- **Projects**: Edit `src/data/projects.ts`
- **Services**: Edit `src/data/services.ts`
- **Pricing**: Edit `src/data/pricing.ts`
- **FAQ**: Edit `src/data/faq.ts`

## Contact Form

The contact form is structured for easy backend integration. Connect Formspree, Resend, EmailJS, or a custom API in `src/components/Contact.tsx`.
